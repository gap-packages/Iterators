# Iterators -- Iterators of orders of simple groups and more

## A GAP 4 Package --

Author and Maintainer:  Stefan Kohl, https://stefan-kohl.github.io/


## Abstract

This package currently provides implementations of iterators running through

 - orders and descriptions of non-abelian finite simple groups  sorted by in-
   creasing order, and

 - the groups in various group libraries coming with GAP,

respectively.


## Requirements

This version of  Iterators needs GAP >=4.16.1  with the default set of inclu-
ded packages. Some functions need the program primecount by Kim Walisch 

    https://github.com/kimwalisch/primecount

to be installed on the system.


## Installation

Like any other GAP package,  Iterators is usually installed in the  pkg/ sub-
directory of the  GAP distribution.   This is accomplished  by extracting the
package archive file in this directory.  After this  you can load the package
as usual via LoadPackage( "iterators" );.
