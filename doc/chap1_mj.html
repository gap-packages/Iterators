1 Utility functions for prime numbers

1.1 Counting prime numbers and finding the \(n\)th prime

The following functions require the program primecount [Wal20] by Kim Walisch to be installed on the system:

1.1-1 PrimeCount
‣ PrimeCount( n )( function )

Returns: the number of prime numbers less than or equal to n.

As the combinatorial counting algorithm used by primecount [Wal20] is notably faster than \(O(n)\), it is feasible to count the primes less than, say, \(10^{18}\) in about a minute. The maximum allowed argument is \(10^{31}\) -- but for bounds of that order of magnitude, on a usual PC the computation would take too much resources anyway.


gap> PrimeCount(10^15);
29844570422669
gap> List([1..15],k->PrimeCount(Factorial(k)));
[ 0, 1, 3, 9, 30, 128, 675, 4231, 30969, 258689, 2428956, 25306287, 
  289620751, 3610490805, 48686912930 ]

1.1-2 NthPrime
‣ NthPrime( n )( function )

Returns: the n-th prime number.


gap> NthPrime(10^12);
29996224275833

1.2 Iterating over the prime powers

1.2-1 PrimePowersIteratior
‣ PrimePowersIteratior( )( function )
‣ PrimePowersIteratior( finish )( function )
‣ PrimePowersIteratior( finish, chunksize )( function )

Returns: an iterator which iterates over the prime powers in increasing order, starting at 2 -- and ending at finish if specified.

If the third argument chunksize is given, it specifies the length of the interval which is sieved in one go using the Sieve of Eratosthenes. Longer sieving intervals increase the memory requirements and the time needed for initially setting up the iterator, but make iterating over many prime powers faster.


gap> iter := PrimePowersIterator();
<iterator of prime powers>
gap> repeat q := NextIterator(iter); until PowerModInt(2,q-1,q^2)=1;
gap> q;
1093
gap> iter := PrimePowersIterator(1000000);;
gap> qs := [];;
gap> for q in iter do Add(qs,q); od; 
gap> Length(qs);
78734
gap> Number([1..1000000],IsPrimePowerInt);
78734
gap> iter := PrimePowersIterator(10000000,100000);;
gap> qs := [];;
gap> for q in iter do Add(qs,q); od;
gap> Length(qs);
665134
