3.1 Iterating over the orders of simple groups

3.1-1 SimpleGroupsSizesIterator
‣ SimpleGroupsSizesIterator( )( function )
‣ SimpleGroupsSizesIterator( start )( function )
‣ SimpleGroupsSizesIterator( start, finish )( function )

Returns: an iterator which iterates over the orders of non-abelian finite simple groups, in ascending order, starting at order start if specified, up to order finish if specified.

Numbers which are the order of two distinct simple groups occur twice. Default values for start and finish are 1 and infinity, respectively. If the option nopsl2 is set, numbers which occur only as orders of groups of type \({\rm PSL}_2(q)\) are omitted. If the option names is set, the iterator produces not only the group orders, but rather it gives for each group a list which contains (in that ordering) the order, the name of the series, the parameters and a common name.


gap> iter := SimpleGroupsSizesIterator();                      
<iterator of orders of simple groups>
gap> NextIterator(iter);
60
gap> NextIterator(iter);
168
gap> NextIterator(iter);
360
gap> iter := SimpleGroupsSizesIterator(1:names);;
gap> NextIterator(iter);
[ 60, "Alt", [ 5 ], "A5" ]
gap> NextIterator(iter);
[ 168, "A", [ 2, 2 ], "PSL(3,2)" ]
gap> NextIterator(iter);
[ 360, "Alt", [ 6 ], "A6" ]
gap> NextIterator(iter);
[ 504, "A", [ 1, 8 ], "PSL(2,8)" ]
gap> NextIterator(iter);
[ 660, "A", [ 1, 11 ], "PSL(2,11)" ]
gap> iter := SimpleGroupsSizesIterator(1:nopsl2,names);;
gap> NextIterator(iter);

gap> NextIterator(iter);

3.2 Counting the simple groups of order up to a given bound

The following functions make use of the function PrimeCount (1.1-1), and therefore require the program primecount [Wal20] by Kim Walisch to be installed on the system:

3.2-1 NumberOfSimpleGroupsOfSizeAtMost
‣ NumberOfSimpleGroupsOfSizeAtMost( n )( function )

Returns: the number of non-abelian simple groups of order less than or equal to n.

Set the Info level of the Info class InfoSimpleGroupsSizes to a value greater than 0 in order to get intermediate information on the progress from time to time when running a longer computation.


gap> NumberOfSimpleGroupsOfSizeAtMost(10^10);
493
gap> NumberOfSimpleGroupsOfSizeAtMost(10^20);
403874
gap> NumberOfSimpleGroupsOfSizeAtMost(10^30);
567362181
gap> NumberOfSimpleGroupsOfSizeAtMost(10^40);
907948153951
gap> NumberOfSimpleGroupsOfSizeAtMost(10^50);
1556185805218446

3.2-2 PositionInListOfSimpleGroupsSortedBySize
‣ PositionInListOfSimpleGroupsSortedBySize( G )( function )

Returns: the position of the non-abelian simple group G in the list of non-abelian simple groups sorted by increasing order.

If there are two simple groups of the same order, it is not specified which of the two possible positions is returned.


gap> PositionInListOfSimpleGroupsSortedBySize(AlternatingGroup(5));
1
gap> PositionInListOfSimpleGroupsSortedBySize(AlternatingGroup(30));
2695155612
gap> PositionInListOfSimpleGroupsSortedBySize(PSL(3,3));

gap> PositionInListOfSimpleGroupsSortedBySize(PSL(5,5));

gap> PositionInListOfSimpleGroupsSortedBySize(PSU(5,3));

gap> PositionInListOfSimpleGroupsSortedBySize(Sz(8));
