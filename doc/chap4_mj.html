4 Installation and Auxiliary Functions

4.1 Requirements

This version of Iterators needs at least GAP 4.10.2 with the default set of included packages. It is completely written in the GAP language, and can be used on all platforms for which GAP is available. However, some functionality requires the program primecount [Wal20] by Kim Walisch to be installed on the system.

4.2 Installation

Like any other GAP package, Iterators is usually installed in the pkg subdirectory of the GAP distribution. This is accomplished by extracting the distribution file in this directory. As usual, you can load Iterators via LoadPackage( "iterators" );.

4.3 The testing routines

4.3-1 IteratorsTest
‣ IteratorsTest( )( function )

Returns: true if no errors were found, and false otherwise.

Performs tests of the Iterators package. Errors, i.e. differences to the correct results of the test computations, are reported. The processed test files are in the directory pkg/iterators/tst.

4.3-2 IteratorsTestExamples
‣ IteratorsTestExamples( )( function )

Returns: nothing.

Runs all examples in the manual of the Iterators package, and reports any differences between the actual output and the output printed in the manual.
