2.1 Iterating over the Small Groups Library

2.1-1 SmallGroupsIterator
‣ SmallGroupsIterator( )( function )
‣ SmallGroupsIterator( start )( function )
‣ SmallGroupsIterator( start, finish )( function )

Returns: an iterator which iterates over the groups stored in GAP's Small Groups Library, sorted by ascending order, starting at order start if specified, up to order finish if specified.

Default values for start and finish are 1 and the limit imposed by the Small Groups Library, respectively. If the option nonsolvable is set, solvable groups are omitted.


gap> iter := SmallGroupsIterator();
<iterator running over the Small Groups Library>
gap> First(iter,G->not IsAbelian(G));
<pc group of size 6 with 2 generators>
gap> StructureDescription(last);
"S3"
gap> First(iter,G->not IsAbelian(G) and IsSimple(G));
Alt( [ 1 .. 5 ] )
gap> ForAny(SmallGroupsIterator(1,59),
>           G->not IsAbelian(G) and IsSimple(G));
false
gap> ForAny(SmallGroupsIterator(1,60),
>           G->not IsAbelian(G) and IsSimple(G));
true
gap> ForAll(SmallGroupsIterator(61,119),G->IsSolvable(G));
true
gap> iter := SmallGroupsIterator();
<iterator running over the Small Groups Library>
gap> G := First(iter,G->CommutatorLength(G)<>1);
<pc group of size 96 with 6 generators>
gap> StructureDescription(G);
"((C4 x C2) : C4) : C3"
